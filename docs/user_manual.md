# ESP-LEGO V1.0 用户手册

ESP-LEGO 是一套面向创客、学生、教师和快速原型开发者的模块化硬件控制系统。主控会自动发现附近的传感器与执行器；用户可以用自然语言描述目标，由 AI 生成脚本并在主控本地执行。

> 核心体验：连接模块 → 描述想法 → 观察硬件运行。

## 1. 适合做什么

- 创客入门：不必先掌握完整的嵌入式开发流程，也能完成传感器和执行器联动。
- 课堂教学：用于演示条件判断、循环、传感器采集、无线通信和自动控制。
- 快速原型：快速验证智能门铃、环境监测、舵机机构、声音触发等想法。
- 进阶开发：可直接编写 ESP-LEGO 脚本，查看执行日志并调试设备行为。

ESP-LEGO V1.0 适合控制与自动化实验，不适合作为安防、医疗、工业联锁等安全关键系统。

## 2. 系统组成

- ESP32-S3 主控：运行网页、AI 脚本解释器、ESP-NOW 通信和本机 UI。
- 传感器模块：例如温湿度、光照、空气质量、雨滴和振动传感器。
- 执行器模块：例如舵机、门铃或蜂鸣器。
- 可选屏幕：240×240 ST7789 LCD 与 CST816D 触摸。
- 可选麦克风：INMP441，仅用于本地声音强度检测。

## 3. 认识 NOVA 控制台

网页采用深色品牌化控制台设计，默认显示中文。点击顶部的 `EN` 可以切换为英文；切换结果只保存在当前浏览器中，不会上传或写入主控配置。

首页从上到下分为：

- NOVA 星灵：系统状态伙伴，用光核颜色、轨道动作和文字说明当前状态。
- 指令舱：输入自然语言目标、选择示例并生成脚本。
- 系统状态：显示模块、AI 服务与运行引擎是否就绪。
- 模块轨道：显示已知模块及在线状态。
- 声音感知：检测本机 INMP441 的实时音量。
- NOVA 实验室：收纳网络、AI、脚本和日志等进阶功能。

NOVA 只反映真实系统状态，不会虚构设备数据：

| NOVA 状态 | 含义 | 建议操作 |
|---|---|---|
| 正在寻找模块 | 尚无在线从机 | 给从机供电并刷新状态 |
| 还差一步：接入 AI 能力 | AI 地址、Key 或模型尚未配置 | 点击 NOVA 进入实验室 |
| 一切就绪 | 模块和 AI 均已准备 | 在指令舱描述想法 |
| 正在理解你的想法 | AI 请求正在进行 | 保持页面打开并等待 |
| 想法正在行动 | 脚本正在主控上运行 | 观察硬件或查看日志 |
| 正在感知声音 | 五秒麦克风测试进行中 | 对麦克风说话、拍手或轻敲 |
| 与主控失去连接 | 连续多次无法读取主控状态 | 重新连接 `ESP-LEGO-Setup` |

点击 NOVA 会执行当前最有帮助的操作，例如打开 AI 设置、重新检测连接或聚焦指令输入框。

## 4. 首次使用

### 4.1 给设备供电

1. 给主控供电并等待启动。
2. 给需要使用的从机模块供电。
3. 主控会通过 ESP-NOW 自动发现模块。首次发现通常需要数秒。

### 4.2 打开控制网页

1. 在手机或电脑的 Wi-Fi 列表中连接 `ESP-LEGO-Setup`。
2. 该热点通常不提供互联网，这是正常现象；请选择“保持连接”。
3. 浏览器打开 `http://192.168.4.1`。
4. 若系统没有自动弹出配置页，请手动输入上述地址。

页面中的“系统状态”会显示：

- 设备：在线模块数和主控记住的模块总数。
- AI 服务：是否已经保存 API 地址和模型。
- 运行状态：系统待命或脚本正在运行。

### 4.3 配置 AI 服务

点击顶部“实验室”，展开网页中的“NOVA 实验室”：

1. 填写兼容 OpenAI API 的地址、API Key 和模型名。
2. 选择生成方式。
3. 点击“保存 AI 设置”。

生成方式有两种：

#### 手机移动数据（推荐）

适合主控热点没有互联网的情况。

1. 保持控制页面打开，输入指令并点击“生成并运行”。
2. 页面提示后关闭手机 Wi-Fi，保留移动数据，再次点击按钮生成脚本。
3. 重新打开 Wi-Fi 并连接 `ESP-LEGO-Setup`。
4. 回到页面，点击“重连后运行”。

#### ESP32 连接路由器

适合现场有稳定 2.4 GHz Wi-Fi 的情况。

1. 在“互联网连接”中扫描或填写路由器 SSID 和密码。
2. 保存网络设置。
3. 在“生成方式”中选择“ESP32 连接路由器”。
4. 输入自然语言指令并运行。

ESP32-S3 与 ESP-NOW 共用无线资源。联网调用 AI 时设备通信可能短暂停顿，完成后系统会恢复 ESP-NOW 通道。

## 5. 用自然语言控制硬件

在 NOVA 下方的指令舱中输入清晰目标。建议包含设备、条件、动作和时间。

示例：

- `每 5 秒读取一次温度并打印`
- `温度超过 30 度时把舵机转到 90 度，否则回到 0 度`
- `有人按门铃时让蜂鸣器响两次`
- `每秒检查声音强度，超过阈值时打印提醒`
- `让舵机从 0 度缓慢扫到 180 度再返回`

如果有多个同类型模块，系统会要求选择具体设备。给模块设置清晰且唯一的名称可以减少歧义。

新指令开始执行时，系统会停止此前运行的脚本。执行结果可在“NOVA 实验室 → 运行日志”中查看。

主控会在执行前统一检查 AI 返回格式：纯脚本、Markdown 代码块、`{"script":"..."}` 以及被代码块包裹的 JSON 都会转换为纯 ESP-LEGO 脚本。空脚本、损坏的 JSON、超长脚本和 `while(true)` / `while(1)` 无限循环会被拒绝并给出原因，不会直接送入解释器。每段脚本仍受 30 秒硬件安全超时保护；持续监测会自动生成为在 25 秒内结束的计数循环，需要继续监测时再次下达指令。

## 6. 设备状态

“模块轨道”会显示模块名称、ID、能力描述和在线状态。

- 在线：模块最近仍在发送状态，可执行读取或控制。
- 离线：主控仍记得该模块，但当前无法通信。
- 已知：包括在线和离线模块。

离线模块仍可用于查看历史信息，但不要依赖其执行实时命令。

## 7. 本机触摸屏

触摸屏主页按 Sensor 与 Actuator 分类显示模块，并支持最多 20 台设备。列表使用 4 张可见卡片循环复用，因此滚动时不会为每台设备重复分配 UI 对象。

- 点击传感器可查看当前值与近期趋势。
- Doorbell 与 Servo 等执行器显示最近命令状态。
- Servo 滑条拖动时只预览，松手后发送一次命令。
- 离线 Servo 会禁用控制，避免产生“已经执行”的误导。

如果触摸方向不正确，应调整固件中的 `swap_xy`、`invert_x`、`invert_y`，不要通过交换随机 GPIO 处理坐标问题。

## 8. INMP441 麦克风

### 8.1 接线

| INMP441 | ESP32-S3 |
|---|---|
| SCK/BCLK | GPIO4 |
| WS/LRCLK | GPIO5 |
| SD/DOUT | GPIO6 |
| VDD | 3.3V |
| GND | GND |
| L/R | 建议接 GND，不要悬空 |

不需要连接 MCLK。

### 8.2 网页检测

在“声音感知”中点击“开始 5 秒检测”，并在麦克风附近说话、拍手或轻敲桌面。NOVA 会切换为聆听状态，页面显示实时电平和五秒内的峰值。

这里的百分比是相对于数字满量程的 RMS 电平，不等同于经过校准的声压级 dB SPL。网页只读取音量，不录音、不保存、不上传音频。

### 8.3 适用场景

- 拍手或敲击触发灯光、舵机、门铃。
- 环境噪声超过阈值时提醒。
- 判断现场是否出现明显声音事件。

V1.0 不提供语音识别、录音回放或音频直播；这些功能需要更高的内存、带宽和专用算法。

## 9. NOVA 实验室与开发者工具

展开“NOVA 实验室”可以配置网络与 AI，也可以直接注入脚本并查看输出。普通用户无需打开脚本和日志区域；这些工具主要用于调试或验证 AI 生成结果。

示例脚本：

```text
while (true) {
    print(mic_level());
    sleep(500);
}
```

直接注入的新脚本会替换当前脚本。建议先在低风险模块上验证，舵机机构应预留机械限位和安全空间。

## 10. 常见问题

| 现象 | 建议处理 |
|---|---|
| 找不到 `ESP-LEGO-Setup` | 重启主控，确认固件为 Master，并查看串口中 Web Console 启动日志。 |
| 手机提示热点无互联网 | 这是正常现象；选择保持连接，打开 `192.168.4.1`。 |
| NOVA 显示“与主控失去连接” | 确认手机或电脑仍连接 `ESP-LEGO-Setup`，然后点击 NOVA 重新检测。 |
| 找不到从机 | 确认从机供电、固件角色和 ESP-NOW 信道，等待数秒后刷新。 |
| AI 显示未配置 | 点击 NOVA 或顶部“实验室”，保存 API 地址、Key 和模型。 |
| 手机模式无法生成 | 保持页面打开，关闭 Wi-Fi、保留移动数据后重试；生成后重新连接主控热点。 |
| AI 生成后提示脚本格式无效 | 系统已阻止不安全或损坏的结果；重新生成，并把目标写成有限时间窗口，例如“每秒检测一次，共检测 20 秒”。 |
| 运行日志出现 Parse error | 脚本语法不符合设备解释器；保留日志中的行号与错误信息，简化指令后重试。主控不会执行未通过解析的脚本。 |
| ESP32 联网模式失败 | 只使用 2.4 GHz Wi-Fi，检查密码和 API 地址，并查看串口日志。 |
| 设备显示离线 | 检查从机供电、距离和固件；离线状态不会自动等同于命令成功。 |
| 麦克风电平不变化 | 检查 3.3V、共地、GPIO4/5/6 和 L/R，查看串口 I2S 错误。 |
| 触摸返回 `ESP_ERR_TIMEOUT` | 检查 CST816D 地址 `0x15`，并确保 SDA/SCL 各有约 4.7 kΩ 上拉到 3.3V。 |
| LCD 花屏 | 先检查供电、接头和地回流；必要时临时将 SPI 从 10 MHz 降到 2 MHz定位信号完整性问题。 |

## 11. 安全与隐私

- `ESP-LEGO-Setup` 是本地配置热点，不应在公共环境长期开放。
- API Key 会用于请求所配置的 AI 服务；手机模式还会使用浏览器本地存储恢复流程。建议使用具有限额、可撤销的测试 Key。
- 不要在自然语言指令、设备名或日志中填写个人敏感信息。
- 舵机、电机和高功率负载必须使用合适电源、驱动和保护电路，不能直接由 ESP32 GPIO 供电。
- I2C 上拉必须接 3.3V，不要接 5V。
